## 1. プロダクト概要

ブラウザ上で動作する、**FF14 機工士（MCH）のスキル回し練習ツール**。

目的は回しを「組む」ことではなく、**既にある回しを正確に実行できるように練習すること**。

| 項目 | 決定内容 |
|------|----------|
| 目的 | 既存回しを時間どおりに正確に押す練習 |
| 対象ジョブ | 機工師のみ（MVP） |
| 実行環境 | ブラウザ、オフライン完結、サーバーなし |
| 言語 | 日本語のみ |
| 見た目 | シンプル |
| 保存 | `localStorage` のみ（共有・URL共有なし） |
| 技術 | React + TypeScript + Vite |

## 2. 要件まとめ（合意事項）

### 2.1 使い方
- 指示されたスキル列を追従して入力する（厳格モード）
- **失敗しても即終了しない**。最後まで続け、終了後に採点する
- 起動時に **サンプル回しを1本同梱**（機工の開幕）
- ユーザーは回しを編集・追加できる（ローカル）

### 2.2 操作
- 基本はキーボード
- 一部はマウスクリック（ホットバーボタン）
- キー配置は設定画面で変更可能

### 2.3 再現するゲーム要素
含める:
- GCD / リキャスト / キャストタイム
- スキル / アビリティ分類
- アビリティは **GCD 非依存**（GCD中でも撃てる）
- アニメーションロック（初期 **670ms**、設定変更可）
- 先行入力（初期 **500ms**、設定変更可）
- ヒートゲージ / バッテリーゲージ
- オーバーヒート（ハイパーチャージ → ブレイズショット）
- フルメタル準備状態（バレルヒーター → フルメタルバースト）
- クイーン等は **ゲージ消費のみ**（ペット挙動なし）

含めない（MVP外）:
- DPS / 威力計算
- ネットレイテンシ再現
- コンボ切れの厳密管理
- 共有URL・アカウント・他ジョブ

### 2.4 初期値
| 定数 | 値 |
|------|-----|
| GCD | 2500ms（回しごとに変更可） |
| アニメロック | 670ms |
| 先行入力窓 | 500ms |
| Perfect 判定 | ±50ms |
| OK 判定 | ±150ms |

### 2.5 スキルマスタ
- **広め**に機工アクションを収録（手動メンテ想定）
- パッチ追従は手動でよい

## 3. 画面構成

1. **ホーム** — 回し一覧、練習開始、編集、削除
2. **回し編集** — 名前、GCD、初期ゲージ、手順の追加／並替／削除、スキル／アビリティフィルタ

4. **練習** — 次手表示、予告、ゲージ、GCD／硬直、ホットバー、フィードバック

UI方針: 日本語、装飾控えめ、カード過多を避ける。ヒート／バッテリーは細いバーで表示。

## 4. アクション分類と発動ルール

正は `category: "skill" | "ability"`。

### スキル（weaponskill 等）
1. アニメロック／詠唱中は即時発動不可（先行入力は可）
2. GCD 未明けは不可
3. 自身リキャスト／チャージ不足は不可
4. ゲージ・オーバーヒート・フルメタル条件を見る
5. 成功時: GCD開始（`fixedGcdMs` があればそれを使用）＋ゲージ反映＋アニメロック

### アビリティ
1. **GCD は見ない**（GCD中でも発動／予約可）
2. アニメロック／詠唱中は即時発動不可（先行入力は可）
3. 自身リキャスト／チャージ・ゲージ条件のみ
4. 成功時: リキャスト開始＋ゲージ反映＋アニメロック（GCDは消費しない）

### アニメロック
- デフォルト 670ms
- ロック中はスキルもアビリティも出せない
- ゲーム同様、織り込みすぎると次スキルが遅れる（クリップ）要因になる

## 5. 先行入力（重要）

ゲームの「早めから連打して最短発火」を模する。

| 入力 | タイミング | 挙動 | 採点 |
|------|------------|------|------|
| **次に押すべきスキル** | 即時可能 | 実行 | Perfect / OK / Late |
| **次に押すべきスキル** | 待ち ≤ 500ms | キュー（1件、後勝ち）→ 解放瞬間に発火 | 発火時に判定 |
| **次に押すべきスキル** | 待ち > 500ms | **無視**（連打用） | **カウントしない** |
| **違うスキル／アビ** | いつでも | 受け付けない | **押し間違いミス** |

補足:
- 不正解ではステップを進めない（同じ次手のまま）
- キュー表示は UI に「予約: ○○」を出してよい
- マクロ非対応など細部は再現不要。通常アクションのキューのみ

待ち時間の内訳:
- 次がスキル: `max(gcd, animLock, cast, ownRecast)`
- 次がアビリティ: `max(animLock, cast, ownRecast)`（GCD除外）

## 6. ゲージ・状態（機工）

```ts
gauges: { heat: 0–100, battery: 0–100 }
overheatStacks: number      // ハイパーチャージで付与、ブレイズで消費
hasFullMetal: boolean       // バレルヒーターで付与、フルメタルで消費
```

クイーン／タレット: **バッテリー消費のみ**（召喚中AI・DPSは持たない）。

## 7. データ構造

```ts
Skill {
  id: string
  nameJa: string
  category: "skill" | "ability"
  castMs: number
  recastMs: number
  charges?: number
  animationLockMs?: number
  fixedGcdMs?: number
  gauge?: { require?: Partial<Gauges>; delta?: Partial<Gauges> }
  consumeAllBattery?: boolean
  requiresOverheat?: boolean
  grantsOverheatStacks?: number
  requiresFullMetal?: boolean
  grantsFullMetal?: boolean
  reduceRecast?: { skillIds: string[]; amountMs: number }
}

Rotation {
  id: string
  name: string
  gcdMs: number
  initialGauges: { heat: number; battery: number }
  steps: { skillId: string }[]
  isSample?: boolean
  note?: string
  updatedAt: number
}

EngineConfig {
  defaultAnimationLockMs: 670
  queueWindowMs: 500
  perfectWindowMs: 50
  okWindowMs: 150
}

Keybinds {
  [skillId: string]: { key?: string; mouse?: boolean }
}
```

保存キー（localStorage）:
- `ff14-mch-rotations`
- `ff14-mch-keybinds`
- `ff14-mch-config`

## 8. 採点

失敗しても継続。結果画面で集計。

| 指標 | 内容 |
|------|------|
| 正解ステップ | 指示どおり発火できた数 / 総ステップ |
| Perfect / OK / Late | 実行可能になってからの遅れ |
| 押し間違い | 指示と違う入力（タイミング問わず） |
| その他失敗 | ゲージ不足、CD中、硬直中の不正実行など |
| （参考）先行入力使用 | 任意 |

「早すぎ拒否」は採点に入れない。

## 10. 変更履歴（設計合意）

1. 最初は GCD／リキャスト／キャストのみ想定  
2. スキル／アビリティ分類とゲージ（ヒート・バッテリー）を追加  
3. アビリティは GCD 非依存＋アニメロックを仕様調査のうえ採用  
4. サンプル開幕、厳格指示、広めマスタ、GCD 2.50 / 硬直 670 を確定  
5. 先行入力を追加。正解早押しはミスにしない（連打用）  
6. 不正解入力はタイミングに関係なく押し間違いとしてカウント  
7. 実装完了
