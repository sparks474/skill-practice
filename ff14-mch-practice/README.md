# FF14 機工士スキル回し練習ツール

ブラウザ完結の機工士（MCH）スキル回し練習アプリです。  
指示された手順を時間どおりに押す練習が目的で、回しの「最適化」自体は対象外です。

設計の詳細は [DESIGN.md](./DESIGN.md) を参照してください。

## 機能

- 厳格モード: 指示スキルを追従（失敗しても最後まで継続 → 採点）
- GCD / リキャスト / アニメロック / 先行入力
- スキル・アビリティ分類（アビリティは GCD 非依存）
- ヒート / バッテリー / オーバーヒート / フルメタル
- サンプル開幕 1 本同梱
- 回しの編集・追加（`localStorage`）
- キー設定・エンジン定数の変更

## 起動

```bash
cd ff14-mch-practice
npm install
npm run dev
```

## その他コマンド

```bash
npm run build      # 本番ビルド
npm run preview    # ビルド結果のプレビュー
npm run simulate   # 開幕サンプルの自動完走チェック
```

## 操作

1. ホームで回しを選んで「練習」
2. キーまたはホットバーで指示どおり入力
3. 終了後に Perfect / OK / Late・押し間違いなどを確認

初期キー配置の例: `Q` 整備 / `5` エアアンカー / `E` ダブルチェック / `4` ドリル / `T` チェックメイト / `C` ハイパーチャージ / `F` ブレイズショット など（キー設定画面で変更可）

## 注意

- スキル数値・開幕は練習用近似です。パッチ完全一致は保証しません
- データはブラウザの `localStorage` のみ（共有 URL なし）
- オフラインで動作します（サーバー不要）
